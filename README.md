# Flowboard

Drag-and-drop workflow builder with undo/redo, autosave, and JSON import/export.

## Features

- React Flow canvas with **start / action / condition / end** node types
- Zustand store with history stack for **undo / redo**
- **Autosave** to `localStorage`
- **Export / Import** JSON
- Keyboard shortcuts: `⌘/Ctrl+Z`, `⌘/Ctrl+Shift+Z`, `Delete`

## Stack

React · TypeScript · Vite · `@xyflow/react` · Zustand

## Run

```bash
pnpm install
pnpm dev
```

Open the printed local URL (usually `http://localhost:5173`).
